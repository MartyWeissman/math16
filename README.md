# Math 16A — course materials (GitHub Pages)

Public copies of the Math 16A (Mathematics for Life Sciences, UC Santa Cruz) course materials, served with GitHub Pages.
`index.html` is the course chronology; the folders hold PDFs only.

- `LabManual_v3_0_Student.pdf` — lab manual (page links from the chronology open it at the right page)
- `LiveProblems/` — in-lecture problem sheets, one per lecture
- `Worksheets/` — Tuesday worksheets (student copies) and the Thursday lecture digest template
- `TeachingTeamManual/` — the teaching team's section-by-section manual
- `LectureSlides_16A_Fall2026/` — slide PDFs, once they are posted
- `Study/` — study materials for exams (added as they are developed)

The working copies live in a Dropbox folder, not here. `publish.sh` copies the allowed files in, rebuilds `index.html`, commits and pushes; it refuses to run if an answer key, `.tex`, or `.pptx` file is present or if the chronology links to a missing file. Answer keys and exams are never published.
